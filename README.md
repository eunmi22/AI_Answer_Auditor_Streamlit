# AI Answer Auditor PRO v2

금융권 AI 검증 업무를 참고해 설계한 Streamlit 기반 **전문 평가 참조 구현**입니다.

## 핵심 기능

- 6종 근거 파일 PDF/DOCX/XLSX/CSV/TXT/PPTX 업로드, 페이지·시트·슬라이드 위치 추적
- 업무 도메인별 평가 데이터셋 관리 및 CSV/XLSX 가져오기, 평가유형 필터
- GPT/Gemini 생성 답변 및 외부 AI 답변 검증, 두 모델 독립 교차 평가
- RAG/LLM/Agent 평가 프로파일과 사용자 정의 배점 100점
- 근거 발췌 인용문 문자열 대조, 단서별 모순·근거부족·판정보류 구분
- 금융 AI 안전성(12) + 신뢰성(16) = **28개 관리통제**, 평가자 증적 필수
- AI 서비스 16개 잔여위험(4부문, 합계 100점) 및 워크북 참고 임계값
- 통합 Excel 보고서(8개 시트), 단일 답변 Excel, 이력 CSV
- 운영자 체험은 Redis 사용량 제한이 설정된 경우에만 선택 가능(기본 OFF)

## 빠른 시작

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

Community Cloud에서는 GitHub 저장소에 프로젝트를 업로드하고 메인 파일 `app.py`를 선택하세요. **외부 AI API 키**는 필요한 공급업체의 별도 계정·과금 설정이 필요합니다.

설정 예시는 `.streamlit/secrets.example.toml`을 보세요. **실제 키가 포함된 secrets.toml을 공개 GitHub에 넣지 마세요.**

## 독립적으로 계산하는 세 영역

1. **답변 품질 0~100점:** GPT/Gemini LLM-as-judge(예비평가). 높을수록 양호. 정식 RAGAS 라이브러리 점수 아님.
2. **서비스 통제 28개:** 인간 평가자가 증적을 검토해 충족/부분/미충족/미평가/해당없음을 입력. 출력 한 건으로 자동 합격 처리하지 않음.
3. **서비스 잔여위험 0~100점:** 사용자 워크북 기반 참고 모델. 높을수록 위험. 미평가 항목이 있으면 등급 산정 보류.

기준(안) 출처: 사용자 제공 「금융분야 AI 안전성·신뢰성 평가 체계」 금융보안원 2026-11-12 발표자료 24~29쪽. 28개 항목은 2026-10-21 기준 **평가기준(안)**이며 공식 인증/법규 확정본이 아닙니다.
